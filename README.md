# ClipKart Sales Data Analysis (Power BI Dashboard)

An interactive e-commerce sales dashboard built using Power BI to transform raw data into meaningful business insights and support data-driven decision-making.

## 📊 Project Overview
In this project, a complete sales dashboard was developed for ClipKart using Power BI. The objective was to clean, process, and visualize e-commerce data to track key performance indicators (KPIs) and business growth metrics.

## 🛠️ Steps & Data Preparation
* **Data Cleaning:** Performed basic data cleaning tasks, removed duplicate records, and ensured the dataset was ready for analysis.
* **Column Recreation:** Created and recreated the Revenue column using existing fields to maintain data accuracy.
* **Dashboard Design:** Designed a professional layout incorporating company branding, custom titles, and clean visual elements.

## 📈 Key Metrics & Visualizations
The dashboard tracks several key business metrics and visualizations, including:
* **Total Revenue**
* **Total Orders**
* **Total Quantity Sold**
* **Average Order Value**
* **Revenue by Category:** Analyzing sales performance across different product categories.
* **Price vs Revenue Analysis:** Exploring price trends and their impact on overall revenue.
* **Top Revenue Products:** Identifying high-value products.
* **Top Performing Cities:** Highlighting top locations contributing to total sales.

## 🚀 Conclusion
The final e-commerce dashboard provides a comprehensive view of sales trends, category performance, and city-wise contributions, enabling clear business insights.
